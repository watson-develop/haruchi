### 1-2. 만점왕 수학 플러스: 구조

courseId=100004444(만점왕 수학 플러스 5-1, 2024)에서 강의목록 확인. 기본서(만점왕 수학)와 **동일한 6개 단원**을 다루되, 단원마다 다음 순서로 반복되는 구조:

### 3-6. 새 연산 도입 방식

수&秀특강 4개 과정 서술을 보면 **혼합계산→분수/소수 개념 → 약수·배수/약분·통분/분수 덧셈뺄셈 → 분수·소수 곱셈/비와 비율 → 비례식**의 순서로, **이전 과정에서 배운 개념을 다음 과정이 명시적으로 다시 연결해서 확장하는("~을 연결하여 배우고", "~까지 정리") 인터리브+누적형** 서술 방식이다. 다만 이는 특강(4,5,6학년 통합) 상품에 대한 서술이며, 정규 사고력 과정(레이/프리즘/뉴레인보우) 자체의 연산 도입 순서는 브로슈어에 나와 있지 않음(미공개 — 사고력수학이라는 상품 특성상 연산 자체보다 사고력 영역 중심이기 때문으로 추정되나, 이는 추정이며 확인된 사실 아님).

**따라서 "구몬 몇 레벨이 나눗셈을 다루는가" 질문에는 한국 구몬 공식 자료로 답할 수 없다 — 미공개.** (국제 구몬 커리큘럼 가이드에는 레벨별 내용이 상세히 공개되어 있으나, 이는 한국 구몬과 동일하다는 보장이 없는 별개 국가의 자료이므로 본 문서에는 포함하지 않았다.)
